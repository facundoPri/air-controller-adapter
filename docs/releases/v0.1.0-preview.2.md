# ACA v0.1.0-preview.2

English-language preview of **Air Controller Adapter**, supporting the Motorola MR-01 on Apple Silicon Macs. All first-party documentation, UI labels, permission prompts, action guidance, logs, and errors are now in English. Configuration keys, app identifiers, and existing data paths are unchanged.

## Download and installation

Download **ACA-v0.1.0-preview.2-macos-arm64.zip** under Assets, extract it, and move the complete **ACA** folder to Applications. Open **ACA Studio** and follow **Connection → Set up this Mac**. Keep ACA Capture next to Studio. Rust and Karabiner are not required.

[Full installation and permissions guide](https://github.com/facundoPri/air-controller-adapter#install-and-connect).

## Included

- Button configuration through a 3D model, Normal/Air profiles, and automatic saving.
- macOS actions, shortcuts, AppleScript, shell commands, and JSON macros.
- Bluetooth discovery, permission guidance, and activity logging.
- Mac/headset recording and optional local transcription integration.
- Fixes for queues, process cancellation, drafts, and privileged reader validation.

## Preview limitations

- **Ad hoc signed, without Apple notarization.** Gatekeeper may block opening; consult the installation guide. This is not a stable, distribution-certified release.
- Apple Silicon only. Development tested on macOS 26.6.2; installation on a new Mac and earlier macOS versions still needs native validation, especially reader permissions in its protected temporary location.
- Capture requires administrator authorization and Input Monitoring. Sessions last up to 30 minutes and can be renewed in the app. No permanent service is installed.
- Updates may require renewing permissions. Replace both apps together; historical local configuration is preserved.
- Air mouse is inferred; its physical mode button cannot be remapped. Remote audio is not confirmed. Zoom requires macOS keyboard shortcuts to be enabled.

Automated and package-integrity checks do not replace device, permission, or Gatekeeper testing on another Mac. Dependency notices are inside the ZIP; **SHA256SUMS.txt** verifies its integrity.

## Build verification

72 automated tests passed (67 core and 5 UI); two optional tests were skipped. Optimized arm64 binaries, verified signatures, and a matching reader hash were checked without starting capture. The packaging script repeats these checks on the extracted ZIP.
